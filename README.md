Token launch radar: ranks 200 DeFi protocols by implied token value derived from a sealed DefiLlama snapshot (TVL, 7-day change, age, no-token status), with a filterable dashboard, per-protocol detail pages and farm plans for the 40 watchlist protocols still without a token.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/token-radar-01-kit/input/snapshot.json
```
